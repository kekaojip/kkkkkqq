## 1. Source Chapter 2 的真正因果机器

母本并不是简单：

```text
危险出现
→ 主角逃跑
→ 同伴帮忙
```

真正因果是：

```text
模拟刚开始
→ 主角获得一个当前环境下立刻有用的新资源：水性词条
→ 主角决定模拟里不要无脑乱来，要尽量活久
→ 突然获得一个“明天大概率必死”的死亡通知
→ 过去不敢走的水路，因为新资源第一次变得可赌
→ 必须逃 + 现在终于能逃
→ 逃跑触发群体连坐与追捕
→ 大春高代价帮助
→ 关系认知改变
→ 逃出生天后出现下一路线
```

关键不是“逃跑”这个结果，而是：

```text
NEW_EDGE + NEW_PRESSURE → PREVIOUSLY_INVALID_ACTION_BECOMES_RATIONAL
```

也就是：**新能力 / 新信息让一个原本不成立的动作成立，同时新压力让这个动作从可选变成必要。**

## 2. 老版第002章｜它做对了什么

老版背景还是“青石县药场 / 焚血散 / 药役”阶段。

它的主要链条：

```text
上一章已经选择：借试药进入内院寻找武道机会
→ 次日真正喝焚血散
→ 顾川扛过第一剂
→ 因为药力反应稳定，被留在内院观察七日
→ 终于接触到《引血桩》
→ 第2/3/5/7日持续练习并得到真实进展
→ 第8日第二次加量试药
→ 顾川主动决定在模拟里把危险吃满，用这条命测试极限
→ 《引血桩》短时间有效，但身体最终扛不住
→ 模拟死亡
→ 系统给出人生节点
→ 顾川选择“第7日·健康顾川”建立首个人生存档
```

老版没有为了照母本制造“河妖等价物”。

它直接拿《人生存档》自己的核心问题做推进：

```text
药役碰不到武道
→ 危险试药反而是进入内院的入口
→ 进入内院后接触桩功
→ 模拟允许主角拿未来生命测试第二剂极限
→ 死亡本身产生现实可利用的信息
→ 保存第7日未来自己
```

每一步都从 Target 自己已有的处境和金手指规则长出来。

```text
OLD_STATUS: STRONG
LABEL: TARGET_NATIVE_CAUSAL_ENGINE
```

### OLD 优势 B｜金手指不是“镜头框”，而是事件发动机

老版里“人生模拟器”直接改变主角怎么冒险：

- 现实不敢随便拿命试第二剂；

## 5. 当前 Learning 第002章｜新暴露的问题

### CURRENT 问题 A｜保住了“逃跑”，但没有保住“逃跑为什么现在才成立”

Source：

```text
以前不敢游河
+ 本章刚得到水性词条
+ 明早不跑就会被送去喂妖
= 今晚逃跑合理
```

当前 Target：

```text
第001章本来就已经考虑今晚逃矿
→ 第002章选择“先观察”
→ 得到旧石沟 + 换岗空档
→ 突然出现老坑死亡任务
→ 今晚逃
```

问题是：

- 顾川第001章已经认为“逃矿”是可讨论方案；
- 旧石沟只是让路线更具体，不像 Source 水性词条那样真正改变能力边界；
- “老坑死亡差事”主要承担“复制 Source 必须立刻逃”的压力，因此容易产生人为植入感。

```text
CURRENT_STATUS: WEAK / FORCED
LABEL: ACTION_NECESSITY_MISMATCH
```

### CURRENT 问题 B｜Source Moment Fidelity 出现了“过拟合”

为了保留：

```text
隐藏死亡差事
→ 必须当晚逃
→ 同伴帮助
→ 逃出生天
```


> 不是 Target 自己需要这些事件，而是为了让 Source Chapter 2 的逃跑结构继续成立，反过来给 Target 补条件。

这说明：


### CURRENT 问题 C｜核心金手指在本章更像“播放/选项框”，没有像老版那样成为事件发动机

当前版人生模拟器主要负责：


```text

```

而老版里：

```text

```

本身就直接制造了第二次试药、死亡情报和存档收益。

所以当前版虽然更贴 Source Story Organization，但**更没有把《人生存档》的独特玩法吃透**。

## 6. CH001 + CH002 联合观察

第001章告诉我们：

> 旧重组太抽象，会把关系、等待、共同过去、payoff 展开和欲望升级扔掉。

第002章又告诉我们：

> 只把 Source Story Moments 全部保回来也不够；如果没有再检查 Target 自己的因果和金手指玩法，就可能为了保 Source 结果而给 Target 强行补触发器。

所以目前出现两个相反方向的失败模式：

```text
FAILURE_A: OVER_ABSTRACTION
Source Moment → Function → 自由重组
结果：承重 Story Components 失血

FAILURE_B: OVER_PRESERVATION / NEAR_SKIN_OVERFIT
Source Moment → 尽量逐个保留
结果：Target 为了复现 Source 行为而被迫新增不自然的触发条件
```

真正需要未来验证的中间解不是“更抽象”或“更贴皮”，而可能是：

```text
SOURCE STORY COMPONENT BUNDLE
+
TARGET NATIVE CAUSAL ENGINE
```

## 7. 候选优化方向｜仅记录，不进入工作流

### HYPOTHESIS 1｜TARGET_NATIVE_CAUSALITY_GATE

每个 Source 承重 Moment 进入 Target 前，多问一层：

```text
这个动作在 Source 为什么现在成立？
Target 里对应的“能力变化 / 信息变化 / 压力变化”是什么？
如果 Target 没有对应变化，是否只是为了保 Source 行为而新造触发器？
```

候选失败信号：

```text
REMOVE_NEW_TRIGGER_TEST:
如果删掉为了对齐 Source 新增的“死亡任务 / 密道 / 突发敌人”，
Target 主角仍然有充分理由做同一个动作，
则这个新增触发器可能只是装饰或强制对齐。
```

### HYPOTHESIS 2｜PRESERVE_CAUSAL_RELATION, NOT NECESSARILY SOURCE_ACTION

未来 Original Recomposition 不一定要保“逃跑”本身。

更重要的是保：

```text
前面获得的新 Edge
+
后面出现的新 Pressure
→ 一个以前不成立的动作 / 选择现在成立
→ 新 Edge 在这里兑现
```

Target 可以让这个动作变成“试药 / 进内院 / 测试未来 / 练武 / 试逃”等，只要因果关系对应且符合 Target 世界。

### HYPOTHESIS 3｜CORE_HOOK_MUST_CAUSE_EVENTS

尤其开书前几章，Target 核心金手指不能只做 UI / 镜头框。

候选检查：

```text
如果移除“人生模拟器”这一机制，本章主要事件还能基本照常发生吗？
```

如果答案接近“能”，则说明核心金手指可能只在旁观剧情，而没有真正驱动剧情。

老版第002章在这个测试下明显更强：没有人生模拟，“拿命测试第二剂 → 死亡获得情报 → 保存第7日未来自己”整条链就无法成立。

### HYPOTHESIS 4｜TARGET_BOOK_PROMISE_CADENCE

Source 章节的 endpoint 可以学习，但不能自动成为 Target 的 endpoint。

还要检查：

```text
Target 自己最核心的读者承诺，多久必须第一次兑现？
```

《人生存档》的核心承诺不是“模拟里一路逃亡”，而是：

```text
走未来
→ 得到未来自己
→ 保存
→ 现实加载
→ 改命固化
```

是否需要在前2~3章更早拿到第一份 Future Asset，应作为独立观察维度，不能被 Source 章节停点完全绑住。
