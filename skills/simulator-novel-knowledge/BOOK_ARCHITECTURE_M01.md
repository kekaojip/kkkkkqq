## 2. 关键洞察（颠覆两个旧假设）

### 2.1 母本每章"看起来不一样"，不是靠"换章节形态"
前200章中 **76% 都是同一种 SIM 章**（面板主导），作者制造变化的方式是**章节内部内容推进**（模拟光幕里的事件/选择/奖励不断变化），而不是每章换形态。

→ 我们之前的"每章换开头/结尾手法"方向**只对 REALITY 章有意义**，对 SIM 章，母本自己也是"面板开场+面板结尾"连用几十章。

### 2.2 "对白 40%"是伪指标
母本对白占比 SIM 中位 38%、REALITY 中位 41%，但**波动巨大（10%-58%）且与乐趣无关**——第5章对白 20% 照样是名场面。对白占比不是"要达标的指标"，是"由本章内容自然产生的结果"。

### 2.3 感叹号的真实用法
母本感叹号中位 24（SIM）/22（REALITY），范围 1-86。**中位约 24**，上不封顶（爆发章86个），下不设限（转场章1个）。

→ 我们 J13 的"≥15"下限**方向对但偏保守**；更准确是"中位24，爆发章40+，转场章可以个位数"。

## 4. 对工作流的建议（提炼为可执行规则）

### 4.1 章节类型标注（替代统一下限）
剧情块必须标注 `CHAPTER_TYPE: SIM / REALITY / MIX`，指标按类型给浮动区间：

```text
SIM 章：面板 50-95 / 感叹号 15-50 / 对白 25-45%
REALITY 章：面板 0-10 允许 / 感叹号 15-45 / 对白 30-50%
字数：所有类型统一 1900-2500（生产口径；母本实测 1619-1849 仅作参考，不构成下限）
```

### 4.2 开头/结尾手法（按类型给默认+例外）
```text
SIM 章：默认面板开场+面板结尾合法（母本90%如此），不判模板化
REALITY 章：默认 EVENT 开场；结尾自由（OTHER/台词/定格）
例外：作者或剧情块要求变化时，SIM 章也可 EVENT/DIALOGUE 开场
```

### 4.3 对白占比取消"指标位"
对白占比从"目标 30-40%"降级为"不设硬门"——由剧情块内容自然形成，只保留"对白不过量到变成纯对话"的软提醒。

### 4.4 感叹号
J13 从"≥15"改为"SIM/REALITY 中位 24，区间 10-50 可浮动；爆发章可 60+"——删掉"每章必须≥15"的下限表述，改为"中位参考"。

## 5. 与旧规约的差异对照

| 旧规则（我们定的） | 拆解后修正 |
|---|---|
| 面板 ≥25/章（所有章） | SIM 50-95 / REALITY 可 0 |
| 感叹号 ≥15/章 | 中位 24，范围 10-50+，不设硬下限 |
| 对白 30-40% | 取消硬门，内容自然决定 |
| 开头必须"入戏第一拍" | SIM 章面板开场即合法（本身就是母本默认） |
| 结尾禁默认面板 | SIM 章面板结尾合法（母本82%如此） |

## Memory line

> **母本前200章：76% SIM 章（面板驱动，面板开场+结尾是默认），22% REALITY 章（事件开场），字数恒稳1600-1900，对白/感叹号自由摆荡。变化来自章内内容推进，不是换形态。工作流指标应按章节类型给浮动区间，取消统一下限。**
