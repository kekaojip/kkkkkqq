## 1. 前200章章节级观察

### 1.1 字数

```text
P10=1619  P50=1698  P90=1849   （min 1553 / max 1976）
```

母本字数非常稳定，但本书生产口径由作者另定为 1900-2500、硬底线 1500。本节只用于理解母本文本密度。

### 1.2 章节表面类型（按面板密度观察分组）

```text
SIM：152章 ≈ 76%
REALITY：43章 ≈ 22%
MIX：5章 ≈ 2%
```

这些标签只用于研究结构，不规定 Target 章节必须按相同比例生产。

### 1.3 表面指标分布

| 指标 | SIM 章观察值 | REALITY 章观察值 |
|---|---|---|
| 面板行 | P10 66 / P50 80 / P90 96 | P10 0 / P50 0 / P90 1 |
| 感叹号 | P10 9 / P50 24 / P90 53 | P10 11 / P50 22 / P90 50 |
| 对白占比 | P10 25% / P50 38% / P90 49% | P10 30% / P50 41% / P90 49% |

观察结论：这些指标随内容自然摆荡，不能单独预测章节是否好看，因此不进入生产 Gate。

### 1.4 开头/结尾观察

```text
SIM 章常见面板承接与面板结果
REALITY 章常见事件/对白直入
MIX 多出现在结构过渡位置
```

关键不是“某类型必须怎样开/怎样收”，而是同一个大块内部允许长期保持相近载体，真正变化来自事件和块转场。

## 2. 前200章块级结构观察

基于前200章连续章节重新按“大段承诺/叙事侧重/转场”观察：

```text
观察块数量：约15个
块长度中位：约15章
REALITY 插曲：多为1-6章的短块/短插段
MIX：稀少，主要出现在块切换附近承担转场
SIM：可以连续多章甚至长串存在
```

> 这些数字全部是 `DESCRIPTIVE_REFERENCE_ONLY`。不得推导“SIM 必须写15章”“REALITY 最多6章”“到第15章必须转场”。

### 2.1 母本真正的变化机制

母本的“变化感”主要来自：

```text
长模拟块持续兑现同一大目标
→ 中间事件/选择/获得不断变化
→ 大块承诺完成或局势发生质变
→ 短现实插曲 / MIX 过渡
→ 进入下一块
```

不是：

```text
每章强行换开头
每章强行换结尾
每章强行切 SIM/REALITY
```

因此“块内同型”本身完全合法。

## 3. 扫读层观察

母本容易扫读的核心不是短句数量，而是**剧情坐标密度与承载顺序**：

```text
事情发生
→ 人物马上反应/做决定
→ 必要解释很短
→ 下一件事
```

读者跳过大部分心理和说明，仍能靠：

```text
动作
对白
事件面板
选择
结果
身份/资源变化
```

复述章节主线。

## 4. 旧假设复盘

### 4.1 “每章换壳才有变化”是错误的

前200章存在大量连续 SIM。强制连续两章开头/结尾不得同型，会把自然大块切碎。

### 4.2 “对白40%”是伪 KPI

对白比例波动很大，与章节是否好看没有稳定对应关系。对白是否保留只看它有没有承担关系、信息、冲突或决定。

### 4.3 “感叹号/面板越接近母本统计越像母本”是错误的

统计值描述的是母本结果，不是母本写作原因。把结果数字反向设为目标，会让模型为指标补面板、补喊叫，反而掩埋剧情。

## 5. 对正式工作流的唯一贡献

本文件只给三条高层参考：

```text
1. 块内连续同型合法；转场由剧情结果触发，不由章数触发。
2. 章节先保证 SCAN_COORDINATES：读者跳读也看得见谁做了什么、结果什么变了。
3. 所有数字统计留在知识库，不进入当前生产硬门。
```

正式规则以 `skills/references/simulator-novel-production-contract.md` 为准。
