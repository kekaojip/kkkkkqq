# 技法 05｜宣言驱动（可选，不是每章必有）

> V3.1 status: advisory only

## 是什么

当人物真的需要把目标说出口时，可以用“对象明确 + 话短 + 紧接行动”的宣言增强驱动力。

它不是每章必须出现的结构件，也不要求固定狠话。

## 来源启发

母本里有些目标节点会把对象和下一步一起说出来，让读者迅速知道主角要干什么。这种写法适合：

```text
复仇对象明确
挑战目标明确
守护目标明确
系统选择后马上行动
```

## 怎么用

- 对象具体，避免“我要努力”“我要变强”空话。
- 话尽量短。
- 如果说出来，就尽快接行动。
- 如果一个明确决定或动作已经把目标讲清楚，可以完全不写宣言。

## 红线

- 禁止为了过 Gate 每章硬塞一句狠话。
- 禁止宣言重复读者已经知道的信息。
- 禁止“只喊口号、不改变下一步”的空宣言。

## 与当前规约

`SCAN_COORDINATES` 和 `BLOCK_PROGRESS` 才负责“目标是否真实推进”。宣言只是可选表达方式。

## Memory line

> **宣言是可选加速器，不是发动机；决定和行动已经清楚时，不必再喊。**
