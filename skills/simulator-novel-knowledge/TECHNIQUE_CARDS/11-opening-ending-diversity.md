# 技法 11｜开头与结尾的多样性（防模板化）

## 是什么
章节开头/结尾是**叙事工具**，不是固定公式。真人的做法：开头怎么入戏快怎么来；结尾随便结或留钩子，由本章内容决定，避免连续两章同型。

## 来源母本证据（M01 前10章）
- 开头：第1章对白｜第2章叙述｜第3/4章承接【你选择1】｜第5/6章光幕时间戳｜第7章设定叙述｜第8章事件中段｜第9章宴席对白｜第10章选择面板——10章各不相同
- 结尾：钩子/定格/台词/结算/余波/自然切——第4章甚至无钩子平断

## 开头手法清单（择一即可）
```
OPENING_DIALOGUE  对白开场（重冲突/关系场）
OPENING_EVENT     事件直入（变故/命令砸下来）
OPENING_OBJECT    物件/画面特写（关键道具带信息）
OPENING_CONTINUE  承接上章（"三天后""第二日"）
OPENING_PANEL     系统面板/光幕承接（系统事件延续）
OPENING_THOUGHT   一句内心/判断直接进场
```
硬要求只有：**第一拍入戏**（纯氛围/天象开头=FAIL）。

## 结尾手法清单（择一即可）
```
ENDING_HOOK       悬念钩子（问题/反常/话没说完）
ENDING_FROZEN     定格画面（火光/背影/药碗）
ENDING_LINE       一句台词收尾（宣言/吐槽/承诺）
ENDING_ACTION     行为收束（睡下/离开/喝药）
ENDING_AFTERMATH  爆点余波/反应回合
ENDING_NATURAL    自然断章（无钩子合法）
ENDING_BRANCH     停在"请做出选择"
```

## 红线
- 连续两章不得同型（开头、结尾各算）
- 【可模拟人生：N】/【是否开始模拟】/“来！”不得作为默认章尾——系统提示放章中
- 无钩子断章合法，不视为缺陷

## 验证（我们这书）
第1-4章开头全为对白、结尾全为面板+“来” → 模板化（P13）。修复后第5章开始按 OPENING/ENDING 标注执行。
