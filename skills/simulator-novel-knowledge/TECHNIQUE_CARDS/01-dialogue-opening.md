# 技法 01｜对白开场（可选的人声入场）

> V3.1 status: advisory only

## 是什么

当本章最重要的是关系、冲突或一句话就能带出当前事情时，可以用人物对白直接开场。

**这是可选手法，不是每章模板，也不存在“连续两章用了就自动 FAIL”。**

## 什么时候好用

适合：
- 第一屏需要立刻让人物关系在场；
- 冲突本身从一句话开始；
- 对白能同时带出信息和行动。

不适合：
- 为了“有人声”硬塞寒暄；
- 当前更自然的入口本来是事件、动作、面板或承接，却强行改成对白。

## 怎么用

- 对白要有功能：带信息、冲突、关系或决定。
- 接下来尽快让事情继续发生。
- 同伴是否接话由剧情需要决定，不要求固定陪衬角色完成“对白配额”。

## 红线

- 纯寒暄不能冒充入戏。
- 不为“开头多样性”机械轮换开场方式。
- 当前正式标准只有：第一屏能看见事情或明确目标。

## Memory line

> **对白开场是一种入口，不是一种指标；能最快把读者送进当前事情时才用。**
