# Stage 1 Story-State Non-Instantiation v1.1

> role: Stage 1 canonical story-state boundary
> owner: `skills/book-construction/SKILL.md` v2.4+
> status: production-main
> purpose: keep opening / Target story reality out of Stage 1 unless explicitly author-locked

## First principle

Stage 1 answers:

```text
WHAT BOOK EXISTS
WHAT PROTAGONIST CORE EXISTS
WHAT CORE MECHANISM / GOLDEN FINGER PHYSICS EXISTS
WHAT CANON / WORLD PHYSICS MUST HOLD
WHAT LONG-FORM DIRECTION / ARC CONSTRAINTS HOLD
WHAT ANTI-CHEAT / MUST-PRESERVE BOUNDARIES HOLD
```

Stage 1 does **not** answer：

```text
WHERE CHAPTER 1 STARTS
WHAT THE PROTAGONIST IS DOING IN THE OPENING
WHAT JOB / ROUTINE / HOUSING / LOCAL RELATIONSHIPS EXIST
WHAT SMALL OPENING RESOURCES / TRANSPORT EXIST
WHAT FIRST INCIDENT / TASK / ENEMY / TRANSACTION / VOYAGE / TRAINING EVENT OCCURS
WHAT THE FIRST TARGET MACRO STORY ACTUALLY IS
```

Canonical shorthand：

> **Stage 1 defines the possibility space and long-form orientation. Stage 2 Story Room instantiates actual story reality.**

```text
OPENING_STATE construction
AI-autofilled CURRENT_LOCATION
AI-autofilled ORDINARY_LIFE

AI-created first Target-Macro premise / actor / incident
```

These are permanently outside Stage 1, not temporarily hidden by an override.

```text

F03 WORLD_OPERATING_MODEL
F04 GROWTH_RESOURCE_ECONOMY

F06 SOURCE_CANON_AUTHOR_LOCKS
```

The retired concept：

```text

```

must not reappear as production authority.

F06 may preserve：

```text
SOURCE_IP
CANON_BASE / PRECEDENCE
AUTHOR-LOCKED CANON ERA / major geography when explicitly confirmed
AUTHOR-LOCKED major divergence
AUTHOR_LOCKED_STORY_STATE when explicitly supplied
PROTECTED_UNKNOWNS

```

It must not create opening reality.

## 3. Author-lock exception

If the author explicitly says：

```text
主角第一章必须在木叶村
开局就是海军本部士兵
必须从风车村开始
主角开局已经有一艘船
```

that exact fact may be preserved as：

```text
AUTHOR_LOCKED_STORY_STATE
```

This is preservation of author authority, not Stage 1 creative autonomy.

AI suggestion / research recommendation / old generated draft does not become an author lock without explicit confirmation.

---

## 4. Current Arc boundary

Current Arc may define only directional / structural state：

```text
current growth phase
current capability maturity range
current social / world scale in non-scene terms
arc pressure class
required long-term state change
completion conditions
must-not-skip constraints
```

Current Arc must not instantiate：

```text
opening location
ordinary occupation
first scene container
first employer / local relationship
first ship / transaction / enemy / task / voyage / training event
first Target Macro concrete conflict
```

Hard distinction：

```text
CURRENT_ARC_GOAL
!= CURRENT_TARGET_MACRO_STORY_ENDING
CURRENT_ARC MAY SPAN MULTIPLE TARGET MACRO BLOCKS
ABILITY_MASTERY_ARC != TRAINING_STORY_REQUIREMENT
```

Before any chapter is adopted, Tracking may contain only facts with legitimate authority：

```text
protagonist identity / core
core mechanism state
canon / world hard constraints
explicit author story-state locks
abstract growth phase / Arc direction
protected unknowns
```

Default：

```text
CURRENT_LOCATION: UNINSTANTIATED_BY_STORY
ORDINARY_LIFE: UNINSTANTIATED_BY_STORY
OCCUPATION: UNINSTANTIATED_BY_STORY
HOUSING: UNINSTANTIATED_BY_STORY
LOCAL_RELATIONSHIPS: UNINSTANTIATED_BY_STORY
OPENING_RESOURCES: UNINSTANTIATED_BY_STORY
OPENING_TRANSPORT: UNINSTANTIATED_BY_STORY
```

Do not fabricate values merely to fill state schema.

After adopted prose establishes concrete facts, Tracking may record them normally.

---

## 6. AI autonomy correction

Stage 1 AI autonomy over ordinary world support applies only to **book-level non-story facts genuinely needed for coherent physics / world operation**.

It does not authorize creating：

```text
opening ordinary places
opening supporting characters
opening relationships
opening resources
opening social position
```

If an ordinary detail's main purpose is to give Stage 2 a ready-made place/person/problem, leave it uninstantiated.

Likewise：

```text
supporting long-line direction
stage ladder direction
protagonist long-term journey
```

are creative direction, not ordinary detail autofill.

---

## 7. Failure gates

Any Stage 1 output fails if it creates a concrete opening / Target-story attractor without legitimate authority.

Failure codes：

```text
STAGE1_OPENING_REALITY_OVERREACH
STAGE1_AI_OPENING_LOCATION_LOCK
STAGE1_AI_OCCUPATION_LOCK
STAGE1_AI_ORDINARY_LIFE_LOCK
STAGE1_CHAPTER0_RESOURCE_INSTANTIATION
STAGE1_CHAPTER0_RELATIONSHIP_INSTANTIATION
STAGE1_CURRENT_ARC_SCENE_PRELOAD
STAGE1_TARGET_MACRO_PRELOAD
STAGE1_DIRECTION_AS_TARGET_STORY
```

Repair：

```text
remove concrete story-state instance
→ replace with abstract law / direction or UNINSTANTIATED_BY_STORY
→ rerun Stage 1 boundary gate
```

Do not push the same concrete choice sideways into another Stage 1 file.

---

## 8. Stage 2 handoff

Stage 1 hands Stage 2：

```text
locked identity / protagonist core
locked mechanism physics
locked canon / world physics
abstract growth / Arc direction
long-form orientation
anti-cheat / must-not-violate constraints
explicit author story-state locks only
```

Stage 2 Story Room then has creative authority to jointly instantiate remaining actual story reality：

```text
STAGE1 DIRECTION / CONSTRAINTS
+
AUTHOR SEEDS
+
SOURCE UNDERSTANDING / RESEARCH MATERIAL when useful
→ STORY ROOM
→ WHOLE TARGET MACRO HUMAN STORY
→ AUTHOR MACRO CREATIVE LOCK
→ FORMAL PARTITION
```

No engineering phase may auto-create the missing story just because Stage 1 left it uninstantiated.

## Memory line

> **Stage 1 builds laws, identity and long-form direction, not the opening room or the actual story. Uninstantiated reality is intentional creative space for Stage 2 Story Room, not a downstream autofill queue.**
