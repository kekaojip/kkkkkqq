# Protagonist Cultural Residue v1.0｜现代穿越者文化残留

> role: Stage 1 optional-but-required-when-applicable character foundation reference
> owner: `skills/book-construction/SKILL.md`
> status: production
> story_authority: none
> purpose: preserve believable modern-person cultural residue for transmigration / rebirth / cross-world protagonists without forcing meme spam

## Mission

本协议只在主角明确来自现代社会、互联网时代或具有类似现代文化背景时触发。

它回答：

> **这个人穿越以后，还保留多少现代人的语言习惯、文化联想、吐槽能力、娱乐记忆与社交反应？**

它不决定剧情，不规定每章必须玩梗，不要求主角成为段子手。

---

## 1. Trigger

满足任一时评估：

```text
MODERN_TRANSMIGRATOR
MODERN_REBIRTH
MODERN_PERSON_IN_OTHER_WORLD
CANON_REINCARNATION_WITH_MODERN_MEMORY
```

若主角并非现代背景：

```text
CULTURAL_RESIDUE_STATUS: NOT_APPLICABLE
```

---

## 2. Required fields

适用时至少明确：

```text
MODERN_CULTURAL_RESIDUE
MEME_AWARENESS
MODERN_ANALOGY_TENDENCY
POP_CULTURE_MEMORY_SCOPE
IP_META_AWARENESS
SOCIAL_LIVENESS
SERIOUSNESS_SWITCH
CULTURAL_RESIDUE_LIMITS
```

### MODERN_CULTURAL_RESIDUE

是否保留现代中文互联网、大众娱乐、生活常识、职场/消费/社交表达的自然残留。

### MEME_AWARENESS

不是“梗库”，只表示人物是否会自然识别、联想到或偶尔使用当代网络表达。

### MODERN_ANALOGY_TENDENCY

人物是否会用现代生活经验理解异世界现象，例如把某种荒诞制度、危险设备、社交场面在脑中类比为熟悉的现代事物。

### POP_CULTURE_MEMORY_SCOPE

只记录记忆范围：

```text
BROAD
SELECTIVE
FUZZY
LIMITED
UNKNOWN
```

不得因为“穿越者”自动拥有完整百科记忆。

### IP_META_AWARENESS

同人文尤其要区分：

```text
KNOWN_CANON_MEMORY
FUZZY_CANON_MEMORY
POPULAR_MEME_MEMORY
UNKNOWN_CANON_DETAIL
```

禁止把模糊记忆升级成精确预知。

### SOCIAL_LIVENESS

人物日常是否允许：

```text
吐槽
接话
轻微损人
自嘲
情境玩笑
现代式反问
荒诞感反应
```

这只是权限，不是频率配额。

### SERIOUSNESS_SWITCH

硬原则：

> **轻松感必须知道什么时候收。**

以下场景默认降低网感 / 玩梗：

```text
真实死亡
重大受伤
他人强烈痛苦
不可逆损失
高压生死决策
庄重情绪兑现
需要保留恐惧/悲伤/愤怒重量的场景
```

除非角色 Canon 明确会用黑色幽默应对压力。

---

## 3. No meme quota

禁止：

```text
EVERY_CHAPTER_MEME_QUOTA
EVERY_SCENE_JOKE_REQUIREMENT
CURRENT_HOT_MEME_FORCED_INSERTION
MEME_LIST_TO_WRITER
```

正确关系：

```text
CULTURAL_RESIDUE = available behavioral / linguistic resource
not mandatory decoration
```

人物可以整章不玩梗，只要情境不自然。

---

## 4. Anti-staleness

网络表达时效性高。

Stage 1 只锁：

```text
人物具有现代文化残留与网感权限
```

不锁具体热梗。

具体当前表达密度、类型和时机由 Stage 3 Contemporary Prose Reference 校准。

这样避免 Foundation 被某个年份的流行语冻结。

---

## 5. Foundation relationship

本协议是 F01 的补充，不替代：

```text
PRIMARY_WANT
DEFAULT_RESPONSE
PROBLEM_SOLVING_BIAS
RISK_PROFILE
VALUE_BOUNDARY
```

它只补：

```text
HOW THE SAME PERSON REMAINS CULTURALLY ALIVE AFTER TRANSMIGRATION
```

如果与 F01 冲突：

```text
F01 CORE PERSONALITY > CULTURAL RESIDUE
```

例如一个极度寡言的人即使懂梗，也不应突然变成高频贫嘴。

---

## Memory line

> **穿越不是格式化。现代人换了世界，仍会带着现代人的文化残留、荒诞感和接话方式；但网感是资源，不是配额。**
