# Concept Discovery Protocol v3.0｜最小书核

> role: Stage 1 internal reference
> owner: `skills/book-construction/SKILL.md` v2.6+
> production_authority: none

## Mission

把作者点子整理成**够进入真实故事创作**的书核。

不是把整本书提前问完。

```text
ENOUGH TO START STORY > COMPLETE FUTURE SPECIFICATION
```

---

## 1. Core rule

```text
NOT NEEDED NOW = DO NOT ASK
UNKNOWN FUTURE != MISSING
UNDECIDED FUTURE != CONCEPT FAILURE
```

如果某个问题的不同答案不会明显改变接下来真实故事的构建：

```text
DEFER
```

---

## 2. Minimum book seed

至少知道：

```text
BOOK_MODE / GENRE
SOURCE_IP when fanfic
RAW_PREMISE
PROTAGONIST_CORE
CORE_MECHANISM
CORE_PLAY / READER PLEASURE
AUTHOR_LOCKS
AUTHOR_REJECTIONS
```

这些足以说明：

> 这是什么书、主角大概什么味、金手指怎么玩、读者来看什么。

---

## 3. Protagonist drive

不再要求：

```text
WHY_STOPPING_IS_UNATTRACTIVE
LIFETIME_MOTIVE
FINAL_TRANSFORMATION
```

只需要当前行为可信：

```text
CURRENT_WANT
+ CURRENT INTEREST / NEED / PRESSURE
= ENOUGH
```

合法当前驱动力包括：

```text
好奇
想变强
喜欢研究能力
想要稀有资源
赚钱
自由
享受冒险
保护当前关系
解决当前麻烦
```

长期理由允许从真实故事里长出来。

---

## 4. Book Kernel minimum

Kernel 不再强制九字段齐全。

最小可包含：

```text
BOOK_IDENTITY
CORE_PREMISE
PROTAGONIST_CORE
CORE_MECHANISM
CORE_READER_EXPERIENCE
DIFFERENTIATION_LOCK when needed
AUTHOR_LOCKS / REJECTIONS
OPEN_FUTURE
```

以下按需，而非必填：

```text
PERSISTENT_TENSION
WORLD_REACTION_SPACE
REPEATABLE_STORY_ENGINE_SPACE
LONG-FORM DIRECTION
```

只有真的帮助当前判断时才写。

---

## 5. Presentation status

书名、简介、卖点包装不再阻断进入故事构建。

```text
BOOK_TITLE_REQUIRED_FOR_STAGE1_PASS: false
BOOK_BLURB_REQUIRED_FOR_STAGE1_PASS: false
```

作者想先定包装时可以研究并共创。

否则允许：

```text
BOOK_TITLE_STATUS: DEFERRED
BOOK_BLURB_STATUS: DEFERRED
```

写到需要发布 / 测市场 / 建正式项目展示时再补。

---

## 6. Research

正式创意判断默认搜索校准。

```text
FORMAL_CONCEPT_REPLY_SEARCH_REQUIRED: true
PREFERRED_PLUGIN: Firecrawl
```

适用：

```text
同人 Canon
机制撞车 / 差异化
角色参考
题材生态
书名简介 when actually deciding them
```

研究没有 Canon 决定权。

---

## 7. Collaboration

正确：

```text
author says idea
→ AI helps clarify what matters now
→ author confirms core
→ once enough to start story, stop asking concept questions
```

错误：

```text
core mechanism locked
→ force lifetime drive
→ force ending
→ force title
→ force blurb
→ force all reader-contract fields
```

---

## 8. Gate

Concept 可 PASS 当：

```text
BOOK_CORE_CLEAR_ENOUGH: PASS
PROTAGONIST_CORE_CLEAR_ENOUGH: PASS
CORE_MECHANISM_CLEAR_ENOUGH: PASS
CORE_PLAY_CLEAR_ENOUGH: PASS
AUTHOR_CORE_DECISIONS_RESOLVED_FOR_NOW: PASS
STAGE2_STORY_FREEDOM_RETAINED: PASS
```

允许同时存在：

```text
OPEN_FUTURE
PROTECTED_UNKNOWN
DEFERRED_PRESENTATION
```

## Memory line

> **Concept v3.0：只锁“这是什么书、主角什么味、金手指怎么玩、读者来看什么”。长期动机、终局、书名简介写到需要时再定。**
