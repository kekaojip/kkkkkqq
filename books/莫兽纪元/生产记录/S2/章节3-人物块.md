# S2 第三章 Character Block｜增量

> status: production-main
> chapter: 3

## 林墨（本场落点）
- 第一次真正战斗：城头首杀灰狼 → 独杀二阶铁脊兽（破口危机）
- 身份：码头苦力 → **守城队正式队员（吃军饷）**
- 表现：请战干脆（"我来。"），战后不吹（"梦里学的"）
- 情绪：紧张→杀出火气→力竭→立住的踏实
- 声口延续：赌狗味淡了些，多了一层"真杀过兽"的沉稳——但内心戏仍外放

## 石头（本场）
- 警讯夜砸门叫林墨，把林果托给张婶
- 跟上城墙（"咱就是扛包的"），全程看林墨杀兽，世界观震碎
- 落点：知道墨哥"会杀兽"，更铁，开始有点崇拜但嘴上还是贫

## 林果（本场）
- 被张婶带内城避险，一夜没睡等哥哥
- 见林墨满身血吓哭，得知进守城队吃军饷后抱着他又哭又笑
- 药钱稳了（军饷），守护兑现感

## 陈校尉（新角色，本章引入）
- 守城队军官，挎刀，识货、惜才
- 城头缺战力时喊"会杀兽的上墙"
- 林墨独杀铁脊兽后：收他进守城队，注意到刀法来历（"哪学的？"→"梦里学的"→多看一眼）
- 功能：给林墨身份跳级 + 埋"刀法来历"悬念线（作者真相未公开）

## 不重写 Plot
本块只决定人物怎么落，不改变已批准事件。
