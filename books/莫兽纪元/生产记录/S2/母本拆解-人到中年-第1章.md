## 1. STORY_SITUATION_CAUSE_CHAIN（情境因果链）
末世背景：凶兽横行时代，人类蜷缩在一座座基地市。某基地市刚被凶兽潮摧毁。
- 许青云是基地市城墙守卫/底层武者，全家靠他一人挣钱养家。
- 妻子苏清雪多年前在凶兽侵袭中失踪多年未归。
- 两个孩子（凤玲及一子）在武者学院上学，饭量大、需淬体丹炼体（淬体丹=孩子成长关键资源）。
- 家境贫穷：一室一厅旧屋，两个孩子挤一间，他睡沙发。
→ 这些因果把许青云放进"为生存疲于奔命、既当爹又当妈、异常重视孩子"的处境，是模拟器触发前必须成立的支点。

## 2. STORY_LEVEL_DRIVING_FORCE
类型：**COMMITMENT（守护承诺）+ PROBLEM（生存/经济压力）**
- 主要驱动力是"把孩子健康带大"的承诺与责任，叠加"无钱买修炼资源、只能靠苦熬"的基础问题。

## 3. ACTION_CONTAINER_ROLE
母本核心动作容器：**"明知是模拟，选中一条最危险但最能变强的路（提前驻守城墙抗凶兽）"**。
容器本身改变收益与章末意义（模拟里拼死换来的成长，全保留回现实），因此属于主线价值，不是 skin。

## 4. ACTION_INTENSITY_AMPLIFIER
局部强度来源：**"这是模拟，死了也无所谓"**——卸下现实求生顾虑，把行动强度拉到"主动选最危险岗位、以命换成长"的极限。这让『模拟可以放开死了变强』与『现实必须苟着守护』形成反差张力。

## 5. RETELLING_BRIDGE_NODES（复述桥节点）
- M1 许青云带伤从城外搏凶兽归来（左臂渗血），挂着家庭照，感叹凶兽时代能这样已经不错。
- M2 路过蛋糕店想给自己过生日，但念及两个孩子要买淬体丹，果断舍蛋糕攒钱。
- M3 电视新闻播报：某基地市被凶兽潮摧毁，各基地市收留幸存者。
- M4 孩子抢着拿蛋糕给父亲祝"生日快乐"，许青云眼眶泛红、手颤；女儿哄"别哭鼻子"。
- M5 许青云许愿"能平平安安健健康康活下去"，当晚是最开心的一晚。
- M6 睡沙发时仍在盘算给孩子的钱，想起失踪的妻子，入睡。
- M7 凌晨【最强模拟系统启动】，觉醒面板：天赋九等、功法低等、境界一阶巅峰、战斗/避险技巧普通级、模拟次数1。
- M8 【模拟开始】：明知资质差无资源，主动申请提前驻守城墙 → 战斗技巧提升 → 为护队友力搏强兽 → 濒死时爆发血脉潜力突破一阶之上 → 击杀凶兽 → 愈战愈勇 → 被队长看重获资源 → 兑高阶功法 → 圆熟境 → 靠基础扎实突破【二阶初段】→ 带队力挽狂澜战熟级 → 死于兽潮。
- M9 【模拟结束】全保留回现实：武道境界二阶初段 / 高阶气血法+武技(圆满) / 战斗+避险技巧(精熟级) / 记忆。

## 6. CHARACTER_DRIVE_CHECK（人物驱动力）
- 许青云现在真正想要：不让两个孩子重蹈他"资质差、无资源、卡死一阶"的覆辙 → 舍蛋糕攒淬体丹、拼命挣钱。
- 阻碍：钱、九等天赋、买不起修炼资源、一个人养家。
- 他为什么选"提前驻守城墙"：这是现实里他不敢赌命（要养家），但模拟里他清楚是模拟，愿意用死换一次变强资格。
- 选择后局势变化：从"一阶巅峰困死的普通人"变成"二阶初段+全套圆满功法+精熟技巧"的现实强者，家庭能过更好、孩子训练资源有了着落。

## 7. HUMAN_RETELLING_CORE（真人复述核心）
末世凶兽横行，人类都缩在基地市里过日子。这个叫许青云的中年男人刚在城外跟凶兽干了一架，左手都渗血了，就是出去讨生活回来。他一个人拉扯两个孩子——媳妇苏清雪几年前在凶兽潮里失踪，一直没回来。城里刚又有消息，哪个基地市让凶兽潮给踏平了。

他要养活孩子，孩子在武者学院上学饭量大，还得吃淬体丹炼体，这玩意贵。这天晚上路过蛋糕店，他想起好像是自己生日，都想进去买块蛋糕了，可一想到这钱能给孩子买淬体丹，转头就走了。回家孩子们却自己买了蛋糕，齐声喊"爸，生日快乐"，凤玲那丫头还把蛋糕从冰箱里端出来。这男人四十几年来第一次眼眶发红——穷归穷，孩子懂事。他闭眼许愿，就求一家人平平安安安健健康康。这是他好多年里最踏实的一个晚上。

夜里他睡在沙发上（房子小，俩孩子挤一间屋），翻来覆去想的还是怎么多挣点钱、孩子吃什么。想起苏清雪，想着想着睡着了。

然后凌晨，脑子里突然"叮"一声：【最强模拟系统】启动了，弹出一块半透明板：修为天赋九等（最差），功法是联邦标准的低等货，境界卡在一阶巅峰，战斗技巧就是普通人的水平，一周能模拟一次。他一愣，随即明白过来——金手指！他资质差、又没钱买修炼资源，这辈只能苦熬，现在有东西能让他换个活法了。他不敢出声，怕吵醒孩子。

【模拟开始】。他知道自己资质差、没钱，就干脆选了条最狠的路：主动申请提前驻守城墙，天天跟凶兽玩命。他清楚这是模拟，死了也就死了，所以放开了打。一开始战斗技巧蹭蹭往上涨，有一次为了护队友硬碰更强的凶兽，命都要丢的时候，血脉里那股劲突然爆出来，一嗓子突破了一阶。他把那凶兽宰了，之后越杀越猛。几十年下去，他从无名小卒混成了防守队长，有资源了，换到高阶功法，把武技都练到圆满，靠实打实的基础把境界一路顶上了二阶初段，成了正经二阶武者。再后来带队挡住一次大凶兽潮，已经在兽潮里被杀红了眼、技巧练到精熟级——但那一次，兽潮太猛了，没能彻底挡住，他死在兽潮里。

【模拟结束】。可这一次死得值：武道境界二阶初段、全套圆满的高阶功法武技、精熟的战斗和保命技巧——**模拟里的东西，全带回现实了**。他睁开眼睛，还是那个破沙发，还是凶兽横行的末世，但他已经不是那个卡在一阶巅峰的许青云了。
