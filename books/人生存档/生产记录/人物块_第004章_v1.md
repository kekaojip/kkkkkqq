## 顾川

### 当前状态
- 现实仍停在赤铁矿场首次模拟进行中的节点。
- 模拟里的自己已在黑风寨生活大半年，把《开山拳》练到能实际防身。
- 对周小满有“现实脱身必须带上他”的责任。
- 对秦红英主动送自己逃走留有轻微亏欠感。
- 第003章末倾向走密道继续去青山县城，但尚未确认。

### 本章最想要什么
> **让第一次模拟继续往真正武道和“值得保存的未来自己”推进，而不是只得到一个会粗拳、能活下来的普通未来。**

### 当前阻碍
- 县城武馆需要钱、担保和更干净的身份条件。
- 逃役身份不能公开。
- 《开山拳》能防普通人，面对真正武者仍存在明显层级差距。
- 随着模拟人生变稳定、出现伴侣和孩子，“继续往前走”本身开始有情绪成本。

### 关键反应 / 选择
1. 看到秦红英被押送，不冲动救人，也不把她当陌生路人；接受自己现在仍没能力处理这段关系后果。
2. 武馆门槛坐实后不继续无意义耗时间，先谋生、积资源。
3. 依靠第003章已经获得的识字算账能力进入客栈，不靠天降贵人。
4. 被真正武者打伤后，不把《开山拳》吹成正式武道，而是更清楚当前未来还不够。
5. 与柳青禾的关系靠长期共同生活和经营自然推进，不因为系统或一次照顾立刻动情。
6. 身份从伙计变成丈夫、父亲和经营者以后，仍持续练拳并关注力量差距。
7. 到三十七岁时，第一次承认一条模拟人生本身也会有真实重量，但没有忘掉现实和存档目标。

### 本章变化

```text
章初：把县城视作下一道武道门
→ 县城武馆再次把自己挡在门外
→ 普通生活重新接住他
→ 客栈 / 柳青禾 / 婚姻 / 儿女逐年变成真实人生
→ “有一段好生活”与“真正拥有力量”第一次同时存在
→ 章末：顾川不再只把模拟当攻略图，而开始知道未来自己也可能背着真实的人生重量
```

### 声口 / 行为
- 算得快，但不写成财务报告。
- 面对秦红英被捕可以沉一下，但不英雄上头。
- 被武者压住后可嘴硬 / 记账，但当前不具备报复条件。
- 家庭段落允许更松、更生活化，不能全程保持危机模式。
- 到章尾不发表宏大人生哲学，只让“舍不得抽身”通过具体生活落出来。

### 知识边界
本章可通过模拟新知道：秦红英等人被押进县城；县城武馆当前入门条件；柳青禾、客栈和这条模拟家庭线；多年后《开山拳》仍只能算较成熟的普通拳脚；三十七岁的这条未来生活状态。

仍不知道：首次模拟最终结局、能保存哪个时期、后续是否进入正式武道、现实加载效果、秦红英最终判决、后山老坑真相、远期系统规则。

## 柳青禾｜模拟路线人物

### 基本定位
- 青山县城普通客栈掌柜，寡居。
- 没有隐藏高手、势力背景或系统关联。
- 用人逻辑现实：顾川能识字、算账、干活，所以留下。

### 与顾川关系推进

```text
掌柜 / 伙计
→ 顾川替客栈理账、管货，成为可靠帮手
→ 顾川被武者伤后，她正常照顾自家伙计
→ 长期共同经营、一起处理日常麻烦
→ 两三年后成亲
→ 成为伴侣 / 生意共同体 / 孩子母亲
```

必须慢因果，不允许“照顾一次 → 突然爱上”。

### 性格与功能
- 现实、会过日子、知道普通人该避什么风险。
- 不负责给顾川送武道外挂。
- 她和孩子共同承担“模拟人生越来越真实”的重量。

## 县城武者｜一次性压力人物

- 不设姓名也可以。
- 因结账 / 酒后争执在客栈发火。
- 真正用途：让顾川亲身确认《开山拳》和正式武者之间的差距。
- 不新增长期追杀、血仇或幕后势力。

---

## 常住老镖师｜一次性小收益人物

- 只承担多年后纠正顾川几个《开山拳》发力 / 换步问题。
- 不收徒，不给秘传功法，不打开隐藏势力线。
- 让“多年坚持练习有一点真实积累”可见即可。
