## Fire calibration

外部校准只取一个简单现实逻辑：早期试药/剂量探索通常是“先观察较低暴露后的反应，再依据耐受情况决定后续加量”，安全和毒性反应本身会影响下一剂量。Target 只借这一因果做仙武药场的“首剂观察 → 入内院继续观察 → 第二次加量”，不搬现代医学术语、制度或伦理框架。

## 【剧情块】

### 1｜VOICE + PANEL + EVENT｜MID｜SYSTEM_3 + SYSTEM_5
第一次模拟不是另起背景说明，而是直接接上章末。

模拟里的周小满先把顾川叫醒：“川哥，醒醒，真到咱俩了！”

顾川睁眼时，系统光幕已经展开：

【第一次人生模拟进行中】
【现实锚点：青石县药场】
【当前分支：借试药进入内院，寻找武道机会】
【模拟时间：次日清晨】
【现实时间：冻结于模拟开始时刻】

顾川第一反应不是重复读规则，而是吐槽一句：“行，开局就是喝药，统子你是真不让我热身啊！”随后和周小满一起被叫去试药房。

局势变化：第一次模拟从抽象功能正式变成正在发生的生活事件。

### 2｜EVENT + VOICE｜FAST
卢管事把两人送进试药房。房里第一次出现内院药师，暂名韩药师，只承担当前节点功能：看药效、记反应、决定谁需要继续观察。

韩药师把同样分量的焚血散放到两人面前，只交代一句：喝完坐着，不许吐，谁的药力反应异常就立即报。

周小满低声问顾川：“现在跑还来得及不？”
顾川回他：“都坐药碗前了，你要不先问问窗户认不认你这个亲戚。”

两人把药喝下。

局势变化：上一章的“明日试药”第一次在模拟里真正发生，逃避空间被关掉。

### 3｜EVENT + BURST｜SLOW
焚血散药力发作必须写成具体身体递进，不一句“很痛”带过：

1. 第一股热从胃里炸开，顾川先觉得腹部像吞了口滚水。
2. 热意迅速往胸口和四肢散，他呼吸开始发紧，额头立刻见汗。
3. 周小满先撑不住，骂了一句后蜷下去，负责观察的人马上把他拖到一边处理。
4. 顾川手背与脖颈开始泛红，但意识仍清楚，韩药师因此让人继续记他的反应。
5. 最强一阵药力冲上来时，顾川身体发抖，却仍完整撑住，没有昏过去。
6. 药劲回落后，他第一句不是“我好痛”，而是在心里骂系统：“模拟第一天就给我上强度是吧！”

局势变化：周小满因反应过重退出当前观察；顾川因为完整撑过首剂，被韩药师注意到。

### 4｜EVENT + HISTORY｜NORMAL
韩药师没有夸顾川，只让卢管事把顾川留下，转去内院观察七日；周小满被送回外院休养。

顾川跟着人第一次真正跨进药场内院。

HISTORY / 共情锚不少于80字：过去八个月，药役最多只能把药材送到内院月门外，里面的东西有人出来接。顾川偶尔能听见院内练功时的喝声，也见过穿短褂的药徒提着药桶进出，但他这种药役连门槛都不能踩。现在他不是靠关系，也不是靠天赋，是把自己当了一回试药耗材才换到这七天。

局势变化：顾川第一次实际进入此前摸不到的武道资源区，但代价仍然是“继续当试药人”。

### 5｜EVENT + PANEL｜NORMAL｜SYSTEM_3
内院为了观察焚血散在人体内的走向，会让继续试药的人每天跟着药徒打一套最基础的《引血桩》，用来活动气血、让药力散开，方便药师看反应。

这一设定只锁当前最小用途：
- 《引血桩》是最基础的炼体动作，不等于正式高阶功法。
- 顾川可以学动作和运力经验，但七天不足以让他突然跨入完整武道境界。

模拟光幕用几个具体节点推进七天，不写纯年份流水：

【模拟第2日：你第一次跟着药徒学习《引血桩》，动作错了大半。】
【模拟第3日：你借昨天试药后的余热再练一遍，终于能把整套架子打完。】
【模拟第5日：你开始知道哪几个动作能让胸腹那股残余热意更快散开。】
【模拟第7日：你已能独立完整打完《引血桩》，但仍未踏入正式武道境界。】

每个节点正文都必须落一个实际动作/结果，不允许只念面板。

局势变化：顾川第一次拿到真正可保存的“未来技艺与经验”，模拟开始产生可兑现资产。

### 6｜BRAIN + VOICE｜EXPAND
顾川必须用不少于120字把这七天的价值算清，但只算到当前够行动：

- 分支2确实能把试药变成进入内院的门票，这条路成立。
- 《引血桩》虽然只是基础，却是他八个月来第一次真正学到武道相关内容。
- 最关键的是，现实中的他还没经历这七天；只要模拟最后能把“第七日的自己”存下来，现实就有机会直接调用这七天积累的动作、运力和身体适应经验。
- 他现在不急着幻想十年后，只需要先确认第一次存档能不能做成。

声口要外放：“七天也算未来！蚊子腿先薅下来再说！”

局势变化：顾川不再把“未来自己”理解成一定要几十年后的大佬，第一次发现短期存档也能滚雪球。

### 7｜EVENT + VOICE｜MID
第八日，韩药师再次叫顾川进试药房。

这一次桌上的焚血散比第一次明显多。韩药师只解释当前剧情需要的信息：首剂反应尚在可控范围，今天加量，再看一次。

顾川知道现实里的自己以后迟早会碰到这一拍，于是没有用周小满教他的装吐办法作弊。他要的是完整情报：这具身体在没有额外底牌时，第二剂到底能扛到哪。

他看着药碗，在心里给自己一句明确决定：“模拟里的命就是拿来踩坑的。今天这碗，我喝到底！”

随后直接喝下。

局势变化：顾川主动用模拟承担现实不该承担的风险，开始探测危险上限。

### 8｜EVENT + PANEL｜SLOW｜SYSTEM_3
第二剂发作比第一次凶得多。

顾川立刻用这七天学的《引血桩》运转身体。前几轮动作确实把药力压下去一截，证明刚学到的技艺有用；但随着药力继续堆高，他的动作开始变形，胸口灼痛加重，最后再也撑不住。

不新增复杂医学解释，也不靠旁白诊断。他只用亲身体验得到三个现实可用结论：
1. 第一剂他能扛；
2. 《引血桩》确实能帮助他承受焚血散；
3. 以当前身体状态直接吃第二次加量，仍会死。

光幕落下：

【模拟第8日】
【你接受第二次焚血散试药】
【你尝试以《引血桩》疏散药力】
【短时间有效】
【药力继续加重】
【你失去意识】
【本次人生模拟结束】
【结束原因：死亡】

局势变化：第一次模拟用一条命换回明确的风险边界，同时证明《引血桩》不是摆设。

### 9｜PANEL + BURST｜SLOW｜SYSTEM_4
模拟结算是本章真正的爽点，按六拍以上展开：

1. 【本次模拟时长：8日】出现，顾川先骂一句“八天就没了？！”
2. 【已记录人生节点：首剂试药后】亮起，他意识到死亡前的过程没有白跑。
3. 【已记录人生节点：进入内院第7日】亮起，呼吸一下提起来。
4. 【该节点保留：《引血桩》完整动作与7日练习经验】出现，顾川手指直接攥紧。
5. 【该节点身体状态：第二剂前 / 无致命损伤】出现，他立刻明白哪个节点最值钱。
6. 【可选择一个人生时期建立首个人生存档】亮起，这是最大一拍，顾川整个人兴奋起来。
7. 另列“第8日死亡前”节点，但明确其身体已经处于严重药伤状态，让选择不是白送的正确答案。

局势变化：第一次模拟终于产出可以被现实调用的“未来自己候选”。

### 10｜BRAIN + PANEL + DECLARE_TARGET｜EXPAND → BRIDGE_FAST｜SYSTEM_4 + SYSTEM_5
顾川不拖长分析，围绕“存哪个自己”做第二个短推演：第1日太早，没有《引血桩》；第8日虽然经验最多，但身体已经被第二剂打坏；第7日刚好处在健康峰值，又带着完整七日练习经验。

他直接拍板：

“焚血散是吧？明天现实里再见！”
“这条模拟命死得不亏，存第七日！”

系统确认：

【已选择人生节点：模拟第7日】
【正在建立人生存档……】
【存档编号：001】
【存档对象：第7日·顾川】
【状态：健康】
【修为：未入正式武道境界】
【技艺：《引血桩》基础掌握】
【经验：七日内院试药与练习经历】
【人生存档创建成功！】

正文停在【人生存档创建成功！】。

不在本章提前写现实加载，也不提前写第二天现实试药。下一章才兑现“第七日顾川”回到现实到底有什么用。
