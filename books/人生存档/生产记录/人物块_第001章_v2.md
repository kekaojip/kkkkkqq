## 顾川

### 章初状态

- 穿越者，当前和周小满一起被困在青山县北赤铁矿场做矿役。
- 对矿场生活已经熟悉，但不认命；他不是单纯受苦，而是一直在找“怎么出去、怎么真正获得力量”的出口。
- 人生存档模拟器长期灰着不可用，今天第一次出现只剩十分钟的明确初始化倒计时，所以章初同时存在两种东西：现实里的长期憋闷，以及一个终于可能兑现的期待。
- 他嘴贫、脑子快、习惯算收益；敢赌，但在真正下注前会先看当前代价与可操作空间。

### 本章反应链

**和周小满谈逃矿**
- 顾川再次提出趁换岗逃走，不是临时冒出的热血，而是长期不甘继续被困的自然表达。
- 周小满认为“外面未必比矿场更容易活”，顾川听得懂这个现实判断，但不会因此接受“那就一辈子待着”。
- 对话里可以有熟人之间的自然接话感，不写成两个 NPC 轮流解释设定。

**看系统倒计时**
- 顾川知道这块界面以前一直不可用，所以“今天终于出现倒计时”本身就足够让他在意。
- 他可以边干活边偷看，不必把期待写成宏大独白。
- 当前仍不告诉周小满系统存在。

**被监工催工**
- 顾川不会因为系统快好了就突然顶撞监工。
- 被敲矿筐后先把活继续干起来，说明他很清楚自己现在没有硬碰硬的资本。
- 现实压力存在，但不能把他重新写成纯受气包；他的注意力仍在倒计时和“今天会不会真的多一条路”上。

**两人的过去被带出**
- 顾川知道周小满在妖祸逃难时救过自己，这段关系不是一句“朋友”标签，而是他为什么天然把周小满算作自己人的基础。
- 对被牙人带进矿场、矿契账目把两人困住这件事，他已经经历一段时间，不需要像第一次听到设定那样震惊。
- 回顾只为给现在的“逃不掉”和“系统终于可用”增加真实重量，不让顾川陷进长篇伤感。

**模拟器正式开放**
- 第一反应不是无条件狂喜，而是先确认：首次模拟当前有没有显示需要拿寿命、血气等明显代价去换，是否还有额外开启条件。
- 当前界面没有给出这些代价/条件后，他马上转入自己最擅长的收益判断。
- 他理解到的重点不是背规则，而是：未来的自己如果真的进了武道，现实中的他第一次可能临时握住那种力量；现实再完成改命，就可能把未来成果真正留下。
- 冷却、存档数量上限、远期升级等当前不知道，也不追问。

**欲望扩大并开启模拟**
- 顾川原本只是在找怎么逃出矿场；理解人生存档以后，他第一次意识到“逃掉”可能只是最小目标。
- 这种扩大不要写成天下无敌宣言，也不凭空锁定复仇对象；核心是从“逃离别人给的生活”切到“以后有机会自己决定走到哪”。
- 放饭时周小满仍以为他在琢磨逃矿，顾川不泄露系统，只让对方先吃，自己去人少的位置确认首次模拟。
- 最终人物主动性落在行动：直接开启，而不是继续研究系统。

### 语言 / 行为味

```text
聪明，但不写成系统论文
嘴贫，但只做局部泄压
不认命，但知道没力量时不能乱硬刚
先看代价，再算收益
得到新机会后，会快速把它拿来解决真实人生问题
对周小满有自己人意识，但不靠煽情说明
```

### 本章人物结果

```text
想找机会逃出矿场
→ 等一个长期不可用的系统终于开放
→ 确认它真的能把“未来自己”变成现实筹码
→ 目标扩大到进入武道 / 主动决定人生
→ 立即开启首次模拟
```

## 周小满

### 当前关系

- 顾川当前最熟悉、最可信的人之一。
- 妖祸逃难时周小满救过顾川，两人后来一起进了青山县、一起被矿契困在赤铁矿。
- 这不是一次性“功能同伴”，本章要让读者感到他们已经一起熬过一段日子。

### 当下欲望

先活下来，先把今天和眼前日子过过去。

### 行为逻辑

- 他不是胆小鬼，也不是傻乐工具人。
- 他觉得矿场很苦，但山外有流民、盗匪、妖物，两人又不是武者，所以“至少这里还有饭”是一个朴素、现实的生存判断。
- 对顾川再次提逃矿，他可以熟练地接话，说明这不是第一次讨论。
- 放饭时仍以为顾川在琢磨逃跑，是因为他不知道系统存在，不是为了制造误会。
- 不自动变成系统知情者，不替顾川解释能力，不在本章要求顾川带他一起修炼。

### 本章人物结果

```text
作为顾川当前生活里真实存在的“自己人”与现实派对照
→ 让顾川的不甘和矿场困局有对话承载
→ 章末仍不知道人生存档模拟器
```

## 监工

### 当下欲望

让矿役把活干完，不在意顾川正在等什么。

### 行为逻辑

- 只承担当前现实压力的现场打断。
- 顾川慢了一拍，就敲矿筐 / 催工，让他继续干活。
- 不升级成私人仇恨，不追加虐待桥段，不在本章承担长期反派职责。
- 不知道系统存在。

### 本章结果

把“系统快开放”重新压回真实矿场劳动中，证明顾川此时仍旧没有现实权力。

- 本章不新增牙人现身、阴谋、骗术细节、追债冲突或矿场幕后势力。
- 如果正文用短回顾承载，只写到读者能明白“为什么两人现在不是想走就走”为止。
