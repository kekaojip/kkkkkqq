## Target-World / Fire Bloom

Fire 校准只用于当前节点实现：公开网文中“试药杂役/试药仆”已经是读者能快速理解的低位危险职业容器，因此 Target 使用药役时不再叠加常见的“妹妹重病 / 炮灰诱饵”等现成苦情组合；只保留一个清楚的现实压力——明日危险试药——并让周小满作为活人同伴共同承受。

## 【剧情块】

### 1｜VOICE + EVENT｜FAST
周小满和顾川在青石县药场后院收拾当天用完的药罐。第一句由周小满直接问：“川哥，明天那碗焚血散，你真喝啊？”院里正有人把上一轮试药后高烧不退的药役抬回通铺，周小满明显怕了，劝顾川今晚干脆想办法躲名单。顾川嘴上嫌他怂，自己却很清楚：他们的名字已经在药役册上，真躲只会先挨一轮收拾，明天照样得进试药房。

局势变化：危险从背景变成“明天就轮到他们”的具体问题。

### 2｜PANEL + VOICE｜MID｜SYSTEM_6 前置
顾川眼前从今天清晨起一直悬着一个只有他能看见的灰色界面，功能全部锁死，只剩“首次启动倒计时”。此时还剩最后十分钟。顾川一边干活一边用网文老读者的口气催它：“统子，八个月都熬了，最后十分钟你可别给我蓝屏。”周小满听见他嘀咕，只当他又在骂药场。

局势变化：现实无解，但一个马上完成启动的未知系统给出明确倒计时。

### 3｜EVENT + VOICE｜FAST
卢管事拿着明日试药名册进后院，当众点出顾川和周小满。明天试的是新配的焚血散，能完整撑过药力的人可以减掉十天役期。周小满听完脸都垮了；顾川看到名册最下面还压着上一轮试药人的伤情记录，知道所谓“撑过去”不是一句轻飘飘的风险提示。

卢管事不和他们讨论，只让两人今晚少吃东西、明早空腹去试药房，随后把名册收走。

局势变化：倒计时之外的现实压力被锁死，顾川没有继续拖的空间。

### 4｜HISTORY + VOICE｜NORMAL
顾川穿到这个世界八个月，醒来时就在药场通铺里，原身已经是药役。第一周他就见过一个试药人浑身发紫，被抬回来后没撑过当夜。周小满当时把自己仅剩的半块饼塞给顾川，又偷偷告诉他哪些药能碰、哪些药最好装吐，两个倒霉蛋就这么混熟了。

顾川这些日子不是没想过练武翻身，可药役只负责搬药、熬药、试药，真正的武学和药方都锁在内院。他能接触到“让武者变强”的东西，却偏偏只是被拿来试风险的那一个。

局势变化：解释顾川为什么不愿丢下周小满，也把“想碰到真正武道机会”变成当前欲望，而不是空泛我要变强。

### 5｜BURST + PANEL｜SLOW｜SYSTEM_6
倒计时归零。灰色界面先整个熄掉，顾川以为自己真等来一次死机，下一瞬一行新的字重新亮起。

爆点至少六拍执行：
1. 【人生存档模拟器：首次启动完成】出现，顾川先停住手。
2. 【可模拟人生：1】与【人生存档槽：1】亮起，他意识到“存档”不是装饰词。
3. 系统继续说明：模拟从现实当前状态开始，并会在真正改变人生方向的节点暂停，等待他的选择。
4. 【模拟结束后，可选择模拟人生中的一个时期，将“那个时候的你”保存为人生存档】出现，顾川呼吸开始变急。
5. 【现实中可短时间加载人生存档，获得该时期自己的修为、技艺与战斗经验】亮起，这是最大一拍，顾川整个人真正坐不住/站不稳，情绪直接外放。
6. 最后一组规则补齐：【若利用模拟所得信息，改变现实中一个原本会发生的重要结果，则判定“改命”】【改命成功，可从对应人生存档永久固化一项成果，并获得下一次模拟机会】。顾川从“未来能借”立刻反应到“未来还能留下”。

局势变化：现实仍弱，但第一次出现可以实际破局的工具。

### 6｜PANEL + BRAIN｜MID / EXPAND
系统面板在这一段完整直给，不拆成零散解释。正文执行时面板总量计划 25–32 行，至少包括：当前现实锚点、模拟次数、存档槽、模拟起点、关键分支暂停、未来自己保存、短时加载范围、加载结束回归现实、改命判定、永久固化、下一次模拟资格，以及第一次模拟状态。

顾川必须现场把收益算透，BRAIN 块不少于 120 字：明天的焚血散本来是纯风险，现在却正好能拿来验证模拟。如果模拟里明天就被药废，他今晚就能提前知道怎么躲；如果模拟中的自己借试药接触到武道，甚至几年后练出修为，他就能把那个时期的自己存下来。哪怕现实中的他今晚仍是药役，只要能短时间加载一个更强的未来自己，明天这碗药就不再只能拿命硬扛。更重要的是，他已经提前知道“原本会发生什么”，现实只要把那个结果真正改掉，就有机会把未来的一部分永久留下。系统不是直接把几十年修为白送给他，但它给了他一条能滚起来的路。

局势变化：能力从“看起来厉害”变成顾川眼前可执行的现实方案。

### 7｜PANEL + VOICE｜MID｜SYSTEM_2
系统把第一次模拟的当前岔路直接做成选择：

【当前人生岔路：明日焚血散试药】
【1：只求平安熬过试药，先保住命。】
【2：借试药进入内院，主动寻找接触武道的机会。】
【3：今晚逃离药场，放弃现有身份。】
【请选择。】

顾川逐条判断：1最稳但收益最低；3看着痛快，可他连药场外面的追捕规则都没摸清，第一轮模拟没必要白白浪费；2正好把“危险试药”变成接触武道的入口，而且输的是模拟人生，不是今晚的现实。他选 2。

局势变化：主角不是被系统拖着走，而是第一次主动决定模拟人生怎么跑。

### 8｜VOICE + EVENT + DECLARE_TARGET｜NORMAL
顾川先让周小满今晚别乱跑，明早照常跟他去试药房，别自己先把事情搞砸。周小满问他是不是吓傻了，顾川不解释系统，只让他信一次。

等周小满转开，顾川看着卢管事刚才收走名册的方向，把目标说死：明天那碗药先解决；卢管事这些日子把药役当耗材算的账，等他从这次模拟里摸出路，再一笔一笔往回算。

宣言后不继续抒情，立刻选择开始模拟。

局势变化：系统能力正式对准现实矛盾，顾川由等死位进入主动试错位。

### 9｜PANEL｜BRIDGE_FAST｜SYSTEM_3 起点
系统确认：
【初始岔路已选择。】
【现实锚点已记录。】
【第一次人生模拟开始！】

第一章就在模拟真正启动的一刻停止，不提前写第二章模拟内容，不追加预告腔。

## 人物 / 事件最小关系

- 顾川：主角；药役；明日被安排试焚血散；想接触武道并摆脱被当耗材的处境。
- 周小满：同伴；同为药役；怕事但不是废物，与顾川已有八个月相互照应的关系。
- 卢管事：当前药场管理者；负责点试药名单，是现实压力的具体执行人。本章只承担当下冲突，不提前扩成幕后大反派。
