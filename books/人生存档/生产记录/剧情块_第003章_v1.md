## Target realization calibration

本章把第002章已经建立的“第7日·顾川”存档第一次投入现实。Fire 校准只用于一个机制边界：运动技能/程序性记忆可以通过学习形成稳定执行能力，但身体的体能适应与肌肉状态不是同一件事。因此本章锁定：存档可加载《引血桩》的技艺与七日经验，但现实肉身不凭空获得七日训练形成的体能适应。

## 【剧情块】

### 1｜VOICE + EVENT｜FAST
第一次模拟结算结束，顾川的意识回到现实锚点。周小满仍在药场后院，前一句话的余音都没散，发现顾川突然笑得很明显，问他是不是被明天试药吓傻了。顾川确认现实时间确实没有因八日模拟而向前走。

局势变化：模拟从“未来体验”正式回到现实，顾川手里多了存档001，但现实中的明日试药还没发生。

### 2｜PANEL + VOICE｜MID｜SYSTEM_5 + SYSTEM_6
顾川打开存档001，第一次查看“现实加载”操作规则：

【人生存档：001】
【存档对象：第7日·顾川】
【状态：健康】
【修为：未入正式武道境界】
【技艺：《引血桩》基础掌握】
【经验：七日内院试药与练习经历】
【当前加载资格：可用】
【同一存档在一次改命周期内可加载1次】
【单次加载持续：一刻钟】
【加载内容仅包含存档记录的修为、技艺与战斗经验】
【加载不会把存档时期的身体损伤或身体训练适应直接覆盖到现实肉身】
【完成改命后，该存档加载资格刷新】

顾川本来很想当场试一下，看到“一次改命周期只可加载1次”后立刻收手。明天试药才是最值钱的第一次使用场景，不能为了手痒把机会烧掉。

局势变化：存档从抽象资产变成有明确次数/时长/边界的现实工具，同时形成“必须把这一发留给明日”的现实约束。

### 3｜HISTORY + VOICE｜NORMAL
入夜前，顾川与周小满仍按药役规矩准备明日空腹试药。过去八个月，每一次进试药房，药役能做的都只是听吩咐、喝下去、再看自己扛不扛得住；周小满最早教他的那些吐药、装弱、避危险药的小窍门，都是在完全不知道药会怎么发作的情况下拿命试出来的。

这次顾川第一次提前知道答案。他不向周小满说系统，只让他记住一句：明天药喝下去以后，自己让他怎么站、怎么呼吸，就先照做，别先问为什么。周小满嘴上怀疑，但因为前一夜已经决定信他一次，最终答应。

局势变化：顾川第一次把模拟情报从“只救自己”扩展到现实同伴，同时仍守住系统秘密。

### 4｜EVENT + VOICE｜FAST
次日清晨，现实试药房与模拟里看到的流程高度一致：卢管事把顾川、周小满送进试药房，韩药师在桌后记录，两碗焚血散摆在面前。韩药师只按流程交代喝完不许吐、哪里难受直接说。

周小满紧张地低声问顾川昨天说的办法到底是什么。顾川看到眼前几乎复现的场景，确认模拟情报正在现实里逐项对上，只让周小满等自己的口令。

局势变化：模拟未来开始追上现实，顾川第一次有机会主动改写已经看过的结果。

### 5｜PANEL + BURST + DECLARE_TARGET｜SLOW｜SYSTEM_6
顾川在端药前调用存档001。加载爆点至少六拍：

1. 【正在加载人生存档001】亮起，顾川心跳明显加快。
2. 【技艺：《引血桩》基础掌握——加载成功】出现，他脑中立刻多出七日反复练过的动作顺序与发力节奏。
3. 【经验：七日内院试药与练习经历——加载成功】出现，焚血散什么时候起热、哪一段最凶、哪些动作真正有用都变得熟悉。
4. 【修为：无可加载正式境界】出现，顾川没有境界暴涨。
5. 【现实肉身状态：保持当前】出现，他马上感觉到“会了”和“身体练了七天”不是一回事，动作知道怎么做，现实筋肉仍是今天这副底子。
6. 【剩余加载时间：一刻钟】亮起，他的兴奋彻底外放。

顾川的宣言只对当前具体问题：“这碗药，我不光自己过，小满也给我一起留下！加载！”随后立刻喝药，不扩成长期豪言。

局势变化：第7日未来技艺第一次真正进入现实，核心系统承诺开始兑现。

### 6｜BRAIN + PANEL｜EXPAND
顾川必须有一段不少于120字的即时收益推演，但只算到当前试药够行动的位置：存档不是把第7日整副肉身换回来，所以现实身体仍要吃焚血散的苦；真正值钱的是他提前拥有了七天反复踩过的动作和药力经验。他知道药力先从腹部起、最凶的一波什么时候来，也知道《引血桩》第三式与第五式最能帮胸腹散热。模拟里周小满就是因为完全不会处理药力而更早撑不住。现在他不需要把整套桩功教会周小满，只要让他在最关键的时候照着两个最简单的姿势和呼吸节奏做，哪怕只多撑一会儿，都可能把现实结果改掉。

局势变化：顾川确定第一次“改命”的执行目标不是炫技，而是让周小满不再按模拟结果提前退出试药流程。

### 7｜EVENT + VOICE｜SLOW / MID
两人喝下首剂。药力按模拟经验发作，顾川从一开始就用加载中的《引血桩》疏散热意，因此虽然现实身体仍痛，整体比模拟首剂更稳。

周小满很快开始难受。顾川不讲功法名，也不做长教学，只在关键时刻让他照着自己摆最简单的两个姿势、按口令换呼吸。周小满动作笨、嘴里骂个不停，药力仍把他折腾得够呛，但他因为相信顾川，始终跟着做，没有像模拟中那样迅速失去继续配合的能力。

局势变化：加载的未来技艺不只帮助顾川自己，第一次实际介入另一个人的现实结果。

### 8｜EVENT + BURST｜MID → SLOW
最凶的一波过去。顾川仍坐得住；周小满虽然脸色难看、浑身冒汗，却保持清醒，没有被提前挪回外院。

韩药师根据真实反应改动记录，最后只按流程宣布：“两个都留下，观察七日。”不夸顾川、不收徒、不追问系统。可以注意到顾川提前做了几个类似引血桩的动作，但本章不展开调查或新关系。

局势变化：现实首次出现与模拟明确不同的重要结果。模拟里只有顾川留下，现实里周小满也留下。

### 9｜PANEL + BURST｜SLOW｜SYSTEM_4
系统在韩药师宣布结果后触发第一次改命结算，至少六拍：

1. 【检测到现实结果发生偏移】出现，顾川先愣一下。
2. 【原模拟结果：周小满首剂反应过重，被送回外院】亮起，模拟旧结果被明确列出。
3. 【当前现实结果：周小满保持清醒，进入七日观察】亮起，顾川直接笑出来。
4. 【重要结果已改变】出现，系统确认不是小误差。
5. 【首次改命判定：成功！】出现，顾川呼吸/手指/坐姿出现明显外放反应。
6. 【可从存档001永久固化一项成果】与奖励一起亮起，爆点进入第二层。
7. 【下一次人生模拟机会：待固化完成后发放】压住章尾期待。

局势变化：系统第一次证明“模拟情报可以真正改现实”，本书核心循环完成到改命阶段。

### 10｜PANEL + BRAIN｜MID｜SYSTEM_2 + SYSTEM_4
系统给出本次可固化的两个当前有效选项：

【1：永久固化《引血桩》基础掌握】
【2：永久固化七日内院试药与练习经验】
【请选择】

顾川不做长篇完整分析。七日经历已经作为记忆给了他重要情报，但真正能持续在现实里练、继续提高、以后反复使用的是《引血桩》本身。于是直接选1。

局势变化：临时加载中的核心技艺转成现实永久能力。

### 11｜PANEL + BURST｜BRIDGE_FAST｜SYSTEM_4 + SYSTEM_5
系统确认：

【已选择：《引血桩》基础掌握】
【永久固化完成！】
【当前永久技艺：《引血桩》基础掌握】
【存档001加载资格已刷新】
【首次改命奖励结算完成】
