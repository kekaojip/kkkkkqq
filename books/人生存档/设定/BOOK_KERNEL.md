## K02 CORE_PREMISE

顾川穿越仙武世界，获得“人生存档模拟器”。他可以从现实当前状态开启人生模拟，在模拟里经历完整人生并面对关键分支；模拟结束后，将某一个时期的“未来自己”保存成人生存档。现实中可以短时间加载该存档，获得那个时期自己的修为、技艺与战斗经验。

真正永久成长需要现实改命：利用模拟得到的信息改变一个原本会发生的重要结果，完成改命后，才可从对应存档永久固化一项成果，并获得下一次模拟资格。

## K03 BOOK_READER_CONTRACT

```text
纯小白

```

核心观看乐趣：模拟人生一路展开 → 关键选择 → 未来自己变强 → 回现实加载兑现 → 改命并永久固化成果 → 再模拟。

## K04 PROTAGONIST_DRIVE

顾川是穿越者，嘴贫、脑子快、习惯算收益；敢赌但不无脑送命；对自己人护短，对敌人记账。当前稳定驱动力是研究并利用模拟器，让自己获得力量和主动权。

## K05 CORE_MECHANISM

```text
现实当前状态
→ 开启人生模拟
→ 模拟内正常经历人生
→ 关键节点出现选择分支
→ 模拟结束
→ 保存某一时期的“未来自己”为人生存档
→ 现实可短时间加载该存档的修为 / 技艺 / 战斗经验
→ 利用模拟信息改变重要既定结果
→ 完成“改命”
→ 永久固化对应存档的一项成果
→ 获得下一次模拟资格
```

当前只锁以上会直接影响近期开篇因果的规则。冷却、额外成本、存档数量上限、远期升级形态均为 OPEN_FUTURE，写到需要时再决定。

## K06 WORLD_REACTION

世界只锁最小物理：仙武王朝中武者、宗门、朝廷与妖祸并存，实力会直接影响资源获取与生存空间。具体地图、境界全表、势力层级和经济模型尚未锁定。

## K07 PERSISTENT_TENSION

每次模拟能提前看见人生可能性，但“看见未来”不等于永久拥有未来力量；现实改命才决定哪些成果能真正留下。

## K08 REPEATABLE_STORY_ENGINE

模拟给出人生路径与分支 → 主角判断收益与风险 → 找到值得保存的未来节点 → 回现实借未来力量处理眼前问题 → 改命固化 → 下一轮模拟打开新的可能。

## K09 DIFFERENTIATION_LOCK

与母本明确分离：不采用“一年抽一个词条”“品质概率抽卡”“模拟结束全部继承”作为本书核心机制。保留的是模拟类题材的读者爽感发动机，不复制母本机制本体。
